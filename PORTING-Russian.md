# PORTING.md — Руководство по портированию aruaru-llm (сжатая версия)

> **Примечание**: это сжатый перевод. Полное техническое руководство
> с деталями кода и подводными камнями остаётся доступным только на
> японском в [PORTING.md](PORTING.md) — сверяйтесь с ним перед
> фактическим переносом паттерна.

Сводка переиспользуемых паттернов реализации из этого проекта, на
случай их переноса в другой проект:

1. **Паттерн связи с open-cuda (конфигурация SET)**: зависимость по
   пути на `opencuda-core`/`opencuda-cpu`; вызывает реальное
   выполнение GPU-ядра (`alloc_buffer`→`copy_from_host`→
   `launch_kernel`→`synchronize`→`copy_to_host`).
2. **Классификация намерений на основе правил, спроектированная для
   будущей замены настоящей LLM**: сохранять поле `engine` и всегда
   честно указывать в нём, какая реализация фактически использовалась.
3. **Слой HTTP API через RPoem** (`open-runo-poem-compat`) вместо
   настоящего crate `poem` — нет экстрактора `Data<T>`, общее
   состояние захватывается через closure `Arc::clone`.
4. **Паттерн валидации пустого ввода** (2026-08-06): явный `400 Bad
   Request` вместо того, чтобы пропускать внутренние ошибки
   токенизатора как вводящий в заблуждение `503`.
5. **Паттерн регистрации арендаторов «теневой клон»** (общий с
   `open-web-server`): `TenantRegistry` + эндпоинты `/admin/tenants`.
6. **Настоящая возможность генерации через `opencuda-llm::GptModel`**:
   веса GPT-2 124M — поле `disclosure` никогда нельзя опускать,
   `/v1/chat` и `/v1/generate` нельзя объединять.
7. **Определение оборудования → рекомендуемый размер LLM →
   автозагрузка** (опциональные фичи `hw-detect-vulkan`/
   `hw-detect-directx`, паттерн перекрёстной проверки, честное
   раскрытие того, что это лишь грубая эвристика размер-против-VRAM).
8. **Паттерн плагина перевода** (фича `nllb-translate`): тяжёлая
   опциональная зависимость `rust-bert`/`tch`, изолированная за
   Cargo-фичей, по умолчанию отключена.
9. **Фича диспетчеризации `real-vulkan`** — **Примечание**: пока не
   рекомендуется для переноса в другое место из-за известного
   нерешённого бага (`Linear::forward` не подключает байты SPIR-V из
   `matmul.spv` к `sgemm`, из-за чего `GemmPath::VulkanGeneric`
   немедленно завершается ошибкой).
10. **Паттерн штрафа за повтор**
    (`generate_with_repetition_penalty`, по умолчанию `1.3`,
    переопределяется через переменную окружения).

**Важная оговорка**: GPT-2 124M мала и относится к 2019 году — она
несравнима с современными коммерческими LLM. `/v1/chat` остаётся
основанным на правилах + классификации сходства через энкодер, а не
нейронной генерацией диалога. Это также должно быть раскрыто на
каждой цели портирования.
