特長 / Features

  • Qwen等のモデルを自動ダウンロードして動かす。OpenAI互換の推論口、日本語検索、OCR(/v1/ocr)。 Downloads and runs models such as Qwen; OpenAI-style inference endpoint, Japanese search, OCR (/v1/ocr).
  • 1台のサーバーを複数のアプリで共有(マルチコア・非同期)。 One server shared by many apps (multi-core, async).
  • 知識はGitHubへ自動退避・起動時に自動復元。 Knowledge is backed up to GitHub and restored automatically at start-up.
