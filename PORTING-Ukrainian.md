# PORTING.md — Посібник з портування aruaru-llm (стисла версія)

> **Примітка**: це стислий переклад. Повний технічний посібник з
> деталями коду та підводними каменями залишається доступним лише
> японською в [PORTING.md](PORTING.md) — звіряйтеся з ним перед
> фактичним перенесенням патерну.

Зведення придатних для повторного використання патернів реалізації з
цього проєкту, на випадок їх перенесення в інший проєкт:

1. **Патерн зв'язку з open-cuda (конфігурація SET)**: залежність за
   шляхом на `opencuda-core`/`opencuda-cpu`; викликає справжнє
   виконання GPU-ядра (`alloc_buffer`→`copy_from_host`→
   `launch_kernel`→`synchronize`→`copy_to_host`).
2. **Класифікація намірів на основі правил, спроєктована для
   майбутньої заміни справжнім LLM**: зберігати поле `engine` і
   завжди чесно вказувати в ньому, яка реалізація фактично
   використовувалась.
3. **Шар HTTP API через RPoem** (`open-runo-poem-compat`) замість
   справжнього crate `poem` — немає екстрактора `Data<T>`, спільний
   стан захоплюється через closure `Arc::clone`.
4. **Патерн валідації порожнього вводу** (2026-08-06): явний `400 Bad
   Request` замість того, щоб пропускати внутрішні помилки
   токенізатора як оманливий `503`.
5. **Патерн реєстрації орендарів «тіньовий клон»** (спільний з
   `open-web-server`): `TenantRegistry` + ендпоінти `/admin/tenants`.
6. **Справжня можливість генерації через `opencuda-llm::GptModel`**:
   ваги GPT-2 124M — поле `disclosure` ніколи не можна опускати,
   `/v1/chat` та `/v1/generate` не можна об'єднувати.
7. **Виявлення обладнання → рекомендований розмір LLM →
   автозавантаження** (опційні фічі `hw-detect-vulkan`/
   `hw-detect-directx`, патерн перехресної перевірки, чесне
   розкриття того, що це лише груба евристика розмір-проти-VRAM).
8. **Патерн плагіна перекладу** (фіча `nllb-translate`): важка
   опційна залежність `rust-bert`/`tch`, ізольована за Cargo-фічею,
   за замовчуванням вимкнена.
9. **Фіча диспетчеризації `real-vulkan`** — **Примітка**: поки не
   рекомендується для перенесення в інше місце через відому
   невирішену помилку (`Linear::forward` не з'єднує байти SPIR-V з
   `matmul.spv` з `sgemm`, через що `GemmPath::VulkanGeneric`
   негайно завершується помилкою).
10. **Патерн штрафу за повторення**
    (`generate_with_repetition_penalty`, за замовчуванням `1.3`,
    перевизначається через змінну середовища).

**Важливе застереження**: GPT-2 124M мала і належить до 2019 року —
непорівнянна із сучасними комерційними LLM. `/v1/chat` залишається
заснованим на правилах + класифікації подібності через енкодер, а не
нейронною генерацією діалогу. Це також слід розкривати на кожній
цілі портування.
